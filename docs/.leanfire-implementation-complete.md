## Architecture Notes

### Component Hierarchy
```
LeanFIRECalculator (Main)
├── LeanFIREInputs
├── LeanFIREResults
├── CostComparisonChart
├── GeographicComparison
├── ExpenseReductionPanel
└── FrugalityTips
```

### Data Flow
1. User inputs → CalculatorContext
2. Context calculates results via `calculateLeanFireResults()`
3. Results passed to display components
4. State persisted to localStorage
