## Project Overview
FIRE (Financial Independence, Retire Early) web application featuring "life energy" calculators inspired by "Your Money or Your Life" by Vicki Robin.

## Technology Stack
- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS
- **Backend**: Vercel serverless functions (Node.js)
- **Hosting**: Vercel
- **Data**: Client-side only (localStorage + JSON export/import)

## Current Phase
Phase 1: MVP - Actual Hourly Wage Calculator

## Key Principles
1. Privacy-first (no accounts required, no server-side data)
2. Plain language outputs ("14 work-hours" not just "$X")
3. Assumption transparency
4. Life energy units throughout
